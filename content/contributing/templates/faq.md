FAQ entries are curated by the maintainer, sourced from Discord and community
conversations. If you have a question that belongs here, open an issue with the
question and (if you can) the answer.

```markdown
---
title: <The question, as people actually ask it>
description: <Short summary of the answer>
weight: <lower = higher in list>
---

# <Question>

<Direct answer. No preamble, no "great question" — just the answer.>

<If the answer is nuanced, break it down. Use subheadings if the question has
multiple parts.>

## Common follow-ups

<Optional: questions people ask after the first one.>

## Source

<Where this question came from — Discord thread link, forum post, etc. Helps
others verify the context.>
```

## Guidelines

- **Answer what the docs don't.** If [docs.devin.ai](https://docs.devin.ai)
  answers the question clearly, link there instead of writing a FAQ entry.
- **Answer what actually works**, not what *should* work. If the docs say X but
  the community knows Y is what actually happens, the FAQ should say Y.
- **Keep it linkable.** One question per page so people can share the URL.
- **Source it.** Note where the question came from so others can verify context.
