## Guidelines

- **Be specific.** Show the actual prompt, not a description of it.
- **Be real.** This should come from a situation you personally encountered.
- **Don't duplicate the docs.** If docs.devin.ai already covers this, link there
  and add only what they don't cover.
- **Keep it short.** A good tip is a few paragraphs, not an essay.
