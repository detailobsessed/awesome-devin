# Devin Desktop

Devin Desktop (formerly **Windsurf**) is the local IDE experience — Devin running
on your machine, integrated into a full editor with file access, terminal, and
local tooling.

{{% callout type="info" %}}
**Windsurf is now Devin Desktop.** As of June 2, 2026, Windsurf became Devin Desktop,
and Cascade is being replaced by Devin Local. See the
[migration guide](migration-from-windsurf) for what changed.
{{% /callout %}}
