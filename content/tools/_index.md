Skills are reusable capabilities Devin can load to extend what it can do. Tools
are external utilities and integrations that enhance the Devin workflow.

This is a curated directory — not a firehose. Each entry has a real description,
installation steps, and an honest assessment of when you'd use it.

## Entries

- [DeepWiki & its MCP server](deepwiki): explore an unfamiliar public dependency before changing code.
- [Devin CLI](devin-cli): work from a terminal in your local checkout.
- [Agent Skills](agent-skills): package a repeatable procedure rather than grow an always-on rules file.
- [AGENTS.md](agents-md): keep a short, version-controlled starting point for coding agents.
